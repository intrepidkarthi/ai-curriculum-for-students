# Reusable Prompts — Copy/Paste Pack (Local LLM via Ollama + VS Code Continue)

Use these prompts in class. Paste into Continue chat (Provider: Ollama). Keep them short to fit context windows.

## Session 01 — AI & Generative AI in Industry (Interactive)
- Use‑case ideation
  - "Propose 3 AI use cases for [fintech/healthcare/gaming] with: problem, value, risks, and one metric to track."
- Career map
  - "Given my interests: [inputs], list 3 roles, key skills to learn, and a 4‑week learning plan."
- Diagram
  - "Produce a Mermaid diagram for this pipeline: data → preprocess → model → evaluation → UI."

## Session 02 — DSA for Placements
- Tests first
  - "Generate 6 edge-case tests for an LRU cache implementation, including capacity=1 and frequent repeats."
- Complexity
  - "Explain time/space complexity of LRU cache (hash map + DLL) and where it’s used in real systems."
